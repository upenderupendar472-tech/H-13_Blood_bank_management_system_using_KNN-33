# 🩸 Blood Bank Management System using KNN Algorithm

A comprehensive web application for managing blood donations and requests using Machine Learning (K-Nearest Neighbors) for intelligent donor matching.

## 🚀 Features

- **KNN Algorithm**: Intelligent donor-patient matching based on multiple parameters
- **Real-time Search**: Find donors by blood group and location
- **User Authentication**: Secure login/registration system
- **Admin Dashboard**: Comprehensive system management
- **Blood Inventory**: Real-time tracking of blood units
- **Emergency Requests**: Priority-based blood request system
